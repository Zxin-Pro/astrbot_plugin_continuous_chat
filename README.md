# astrbot_plugin_continuous_chat

AstrBot 群聊连续对话插件：唤醒一次后连续畅聊，无需每句都 @机器人。

## 功能

- **免唤醒连聊**：用户通过 @机器人 或唤醒词唤醒后，后续每条普通消息直接触发 AI 回复，无需再次唤醒
- **滑动窗口超时**：用户每发一条消息都会刷新超时计时器；超过设定时间没说话自动退出，再发言需重新唤醒
- **按「群+用户」隔离**：A 唤醒后，B 发言仍需自己唤醒，互不影响
- **白名单**：可限定只在指定群生效，留空则所有群生效

## 工作原理

- 监听所有群消息（`event_message_type(ALL)`），命中 @/唤醒词则记录「群ID+用户ID」的活跃状态（KV 存储，值为过期时间戳）
- 活跃用户每条消息刷新过期时间戳（`当前时间 + timeout_seconds`），惰性比较判断超时，无定时器，插件重载后未过期状态自动恢复
- 活跃用户的普通消息通过置位 `is_at_or_wake_command` 强制进入 LLM 管线；`on_llm_request` 钩子拦截不活跃用户的 LLM 请求

## 安装

方式一（推荐）：在 AstrBot WebUI 插件市场或通过仓库地址安装：

```
/plugin repo add Zxin-Pro/astrbot_plugin_continuous_chat
```

方式二：下载本仓库 zip，在 WebUI「插件管理 → 从文件上传」安装。

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `wake_words` | list | `["小助手"]` | 唤醒词列表，消息包含任意唤醒词即唤醒（忽略大小写） |
| `timeout_seconds` | int | `60` | 连续对话超时秒数，期间每发一条消息刷新计时，最小 5 秒 |
| `enable_at_wake` | bool | `true` | 允许通过 @机器人 唤醒 |
| `enable_word_wake` | bool | `true` | 允许通过唤醒词唤醒 |
| `whitelist_groups` | list | `[]` | 生效群白名单（群 ID 列表），留空表示所有群生效 |

## 使用示例

1. 群里 @机器人：「@小助手 今天天气怎么样」→ AI 回复，该用户进入连续对话状态
2. 接着直接发：「那明天呢？」→ 无需再 @，AI 继续回复
3. 持续聊天期间每次发言都会刷新 60 秒计时
4. 停止发言超过 60 秒 → 自动退出，再次 @机器人 或喊唤醒词即可重新开始

## 边界说明

- 仅群聊生效，私聊不受影响
- 机器人自己发的消息不会触发任何状态变化
- 以 `/` 开头的指令消息不会触发 AI（但会计入超时刷新）
- 其他用户未被唤醒时，其 @机器人 以外的消息不会触发 AI 回复
